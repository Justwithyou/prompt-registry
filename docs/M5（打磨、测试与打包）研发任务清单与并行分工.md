## 0. 文档用途

M1～M4 已跑通「CRUD + 搜索 + 组织层 + 模板 + 版本 + 加密 + 同步」的完整业务闭环。本文档把 **M5（v1.0 正式版，Day 12～13，约 12 小时）** 的「打磨 + 测试 + 打包」拆成**可多任务并行**的任务清单，目标是从「功能完整」跃迁到「可分发、可安装、体验收尾」的**正式发布物**。

M5 的六大增量（对应排期 §2.6）：

| 功能域 | 排期 | 说明 |
|---|---|---|
| 系统托盘 | §2.6 + T-28 | 托盘图标 + 菜单（唤出/隐藏/退出），常驻后台快速唤起 |
| 全局快捷键 | §2.6 + T-28 | Cmd/Ctrl+K 命令面板、Cmd/Ctrl+N 新建提示词 |
| 深色模式 | §2.6 + T-29 | 三态主题（跟随系统/亮/暗），跟随系统自动切换 |
| 自动更新 | §2.6（T 表并入 T-31） | Tauri Updater 检查/下载/安装 |
| 单元测试 | §2.6 + T-30 | 核心逻辑覆盖率 > 70% |
| 打包分发 | §2.6 + T-31 | Windows/macOS/Linux 安装包 + CI 跨平台 |

M5 的六项功能彼此依赖极弱（均为「打磨」性质，各自独立成轨），是五个里程碑中**并行度最高**的一个，唯一串行前置是 Phase 0 的少量决策拍板。

## 1. M5 完成定义（DoD）

全部为“是”才算 M5 完成，才打 `git tag m5-tag`：

- [ ] 托盘：任务栏/系统托盘出现图标，可唤出、隐藏、退出应用。
- [ ] 快捷键：`Cmd/Ctrl+K` 唤出命令面板并聚焦搜索，`Cmd/Ctrl+N` 快速新建提示词。
- [ ] 深色模式：默认跟随系统，随系统明暗自动切换；可手动覆盖为亮/暗。
- [ ] 自动更新：检测到新版本可提示并下载、安装（配置好 updater endpoints 与公钥）。
- [ ] 测试：核心逻辑单测覆盖率 > 70%，`vitest run` 与 `cargo test` 全绿。
- [ ] 打包：产出 Windows 安装包（本机），macOS/Linux 由 CI 产出；安装包可运行、快捷键可用。
- [ ] ✅ 全部达成 → `git checkout main && git merge m5-release` 后打 `git tag m5-tag`。

> 范围提醒：AI 辅助（`crates/ai`）仍属 P2 之后，M5 不做；`import-export`、`ai-assistant` 等占位 feature 留待后续。M4 遗留的 `sync_engine` 装配（当前 `None`）如需在 v1.0 前补齐，需另行立项，不在 M5 打磨范围内。

## 3. Phase 0 · 决策冻结（串行前置，唯一阻塞点）

> 决策项比 M1～M4 都少，0.5h 内完成；没拍板前五轨不启动。

### 3.1 需拍板的决策点（人定，AI 生成）

| 决策 | 推荐 | 说明 |
|---|---|---|
| 主题三态 | `type Theme = "system" | "dark" | "light"`，**默认 `system`** | 现有 `settingsStore` 只有 dark/light，需升三态并监听 `prefers-color-scheme` |
| 快捷键作用域 | `Cmd/Ctrl+K` 在窗口内走**前端监听**；全局快捷键 `Cmd/Ctrl+K` 用于窗口隐藏时**唤出** | 区分「应用内快捷键」与「全局唤起」，避免角色混淆 |
| 新建快捷键 | `Cmd/Ctrl+N` 全局注册，触发前端新建提示词事件 | 需跨进程：全局快捷键回调 → 事件 → 前端 store |
| updater 端点 | GitHub Releases（`https://github.com/<owner>/<repo>/releases/latest/download/latest.json`） | 正式发布源；若私有分发再换私有端点 |
| updater 公钥 | `tauri signer generate` 生成，**私钥不入 git**，公钥写入 conf | 签名密钥纳入 CI secrets（`TAURI_SIGNING_PRIVATE_KEY`） |
| 覆盖率工具 | 前端 `vitest + @vitest/coverage-v8`；后端 `cargo-llvm-cov`（需 `rustup component add llvm-tools-preview`） | 阈值 > 70%，覆盖**核心逻辑**（非 UI 渲染细节） |
| 打包目标 | Windows：NSIS（主）+ MSI（可选）；macOS：dmg + app；Linux：deb + AppImage | 本机仅出 Windows，macOS/Linux 走 GitHub Actions |
| 版本号 | `0.1.0` → `1.0.0`（`tauri.conf.json`、`package.json`、`Cargo.toml`、`settingsStore.appVersion` 统一） | v1.0 正式版 |

### 3.2 锁定内容（写死，避免并行漂移）

**主题枚举（`src/features/settings/stores/settingsStore.ts`）**：

```ts
export type Theme = "system" | "dark" | "light";
export type ResolvedTheme = "dark" | "light"; // system 下由 prefers-color-scheme 解析
```

**快捷键映射**：

| 键位 | 作用域 | 动作 |
|---|---|---|
| `CmdOrCtrl+K` | 应用内 + 全局 | 命令面板（聚焦提示词搜索/导航） |
| `CmdOrCtrl+N` | 全局 | 新建提示词（事件 → router 跳转编辑器空稿） |

**updater 配置要点（`tauri.conf.json`）**：

```json
{
  "version": "1.0.0",
  "bundle": { "active": true, "targets": "all", "createUpdaterArtifacts": true },
  "plugins": {
    "updater": {
      "pubkey": "<REPLACE_WITH_PUBLIC_KEY>",
      "endpoints": ["https://github.com/<owner>/<repo>/releases/latest/download/latest.json"]
    }
  }
}
```

**capabilities 扩展（`src-tauri/capabilities/default.json`）**：新增以下权限，避免运行时被拒：

```
"global-shortcut:allow-register", "global-shortcut:allow-unregister",
"updater:default", "updater:allow-check", "updater:allow-download-and-install"
```

## 10. 并行协作约束（务必遵守）

1. **文件归属唯一**：`lib.rs`、`tauri.conf.json`、`capabilities/default.json`、`package.json`、`settingsStore.ts` 为跨轨共享文件，P0 冻结后如需改动先广播（尤其 A/C 都触 `lib.rs`、E 也动 `tauri.conf.json`）。
2. **版本号以 P0 锁定为准**：`1.0.0` 统一，任何轨道不得私改。
3. **私钥绝不入 git**：`tauri signer` 生成的私钥 / `TAURI_SIGNING_PRIVATE_KEY` 只进 CI secrets 与本地 `.gitignore`。
4. **覆盖率只对核心逻辑**：UI 渲染细节（CSS/布局/纯展示组件）不计入 70% 阈值范畴，避免为凑数写无意义测试。
5. **快捷键不冲突**：`CmdOrCtrl+K/N` 不得与文本编辑器、浏览器默认行为打架，注册前在目标平台真机验证。
6. **打包产物不入库**：`src-tauri/target/`、`dist/`、`*.msi/*.exe` 保持 `.gitignore` 排除，只把源码与 workflow 提交。
7. **深色模式不破坏现有明确定制**：`data-theme` 机制已在 `AppLayout` 落地，B 轨道只增量加 `system`，不重写整套样式系统。
