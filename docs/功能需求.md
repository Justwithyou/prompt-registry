## 1. 文档概述

### 1.1 文档目的

本文档定义个人提示词管理平台的业务目标、功能范围、优先级、数据安全要求、同步机制、团队扩展能力及迭代路线，作为产品设计、研发、测试和后续迭代的统一依据。

### 1.2 产品定位

一个**本地优先、隐私安全、高度可定制的个人提示词管理平台**，帮助用户完成提示词的创建、组织、模板化、版本迭代、调试、复用、同步与团队分发。

### 1.3 参考产品

**直接竞品（个人提示词管理）**：

- PrompterHub：社区模板与多类型支持
- PromptNest：浏览器扩展，本地优先，一键插入

**版本控制与开发者工具**：
- promptvault-ai：包管理清单、依赖解析、Lockfile 校验
- PromptPal：Tauri 技术栈验证

**团队与工程化平台**：
- PromptLayer：版本控制、监控、协作、A/B 测试
- Langfuse：开源 LLM 工程平台，自托管
- Agenta：配置级版本管理

**浏览器插件类**：
- PromptMaster：智能占位符，多维分类
- AI Productivity Suite：团队提示词库，数据本地

## 2. 项目背景与目标

### 2.1 背景

提示词已成为个人 AI 生产力的核心资产。当前痛点包括：

- 提示词散落在聊天记录、备忘录、文档中，难以检索和复用。
- 高质量提示词缺乏版本记录，迭代过程不可追溯。
- 多设备、多环境切换时，数据同步困难。
- 在线工具存在隐私风险，敏感提示词不愿上传。
- 团队内提示词分发依赖口口相传，缺乏审核和权限控制。

### 2.2 产品目标

- **存得住**：本地优先存储，数据归用户所有。
- **找得到**：项目、分类、标签、全文搜索多维组织。
- **用得快**：模板变量、一键复制、浏览器插件、快捷唤出。
- **管得好**：版本控制、Diff、回滚、变更记录。
- **传得安全**：端到端加密同步，零知识服务器。
- **扩得开**：从个人到小团队，支持共享工作区、角色权限、模板包分发。

### 2.3 核心设计原则

- **本地优先**：默认本地 SQLite 存储，无需联网即可使用。
- **模板化复用**：提示词抽象为带变量的可复用模板。
- **版本即资产**：每次修改可回溯，像代码一样管理。
- **一键可用**：从找到提示词到填入变量并复制，路径最短。
- **可扩展**：预留 MCP、CLI、浏览器插件、WebDAV 等接入能力。
- **隐私可控**：本地模型优先，API Key 本地存储，遥测默认关闭。

## 3. 用户角色与核心场景

### 3.1 用户角色

| 角色 | 说明 |
|---|---|
| 个人用户 | 主要使用者，管理个人提示词库 |
| 团队维护者 | 管理团队共享提示词，审核变更，分配权限 |
| 团队成员 | 使用团队提示词，可 fork 到个人空间修改 |
| 外部只读用户 | 通过分享链接只读访问指定提示词 |

### 3.2 核心场景

1. 创建一条提示词，打上分类、标签，加入某个项目。
2. 将提示词改为模板，使用 `{{变量}}`，使用时填写表单并复制。
3. 修改提示词后自动生成新版本，对比差异并回滚。
4. 换电脑后通过 WebDAV + 加密口令恢复全部数据。
5. 将一组提示词打包为 `.promptpack` 分享给同事。
6. 团队共享工作区中，维护者发布提示词，成员只读使用。
7. 调用 AI 辅助优化提示词，或从需求自动生成提示词。

**无账号体系同步方案**：

- 数据加密后上传至用户自己的 WebDAV 服务器。
- 加密密钥通过 Argon2id 从同步口令派生。
- 换设备时输入 WebDAV 凭证和同步口令即可恢复。
- 冲突解决采用 CRDT，版本历史追加式合并。

## 5. 非功能需求

### 5.1 性能

- 本地搜索响应时间 < 200ms（万级提示词）。
- 应用启动时间 < 2s。
- 同步增量上传，避免全量传输。
- 版本 Diff 渲染流畅，支持长文本。

### 5.2 安全

- 本地数据库加密存储。
- 同步数据端到端加密，服务器零知识。
- API Key、WebDAV 凭证仅存 OS 钥匙串。
- 支持应用锁、自动锁定、加密备份。
- 核心加密逻辑开源可审计。

### 5.3 隐私

- 遥测默认关闭。
- 在线 API 调用前明确提示，支持脱敏模式。
- 优先支持本地模型。
- 用户完全掌控密钥和数据。

### 5.4 兼容性

- 桌面端支持 Windows、macOS、Linux。
- 同步协议兼容标准 WebDAV。
- 导入导出格式兼容 JSON、CSV、Markdown。

### 5.5 可用性

- 从搜索到复制提示词不超过 3 步。
- 模板变量填写界面清晰，支持默认值和下拉选择。
- 版本对比直观，回滚操作可撤销。

### 5.6 可维护性

- 模块化架构，提示词库、模板引擎、同步、安全相互解耦。
- 数据模型支持迁移和版本升级。
- 日志本地存储，便于排查。

## 6. 数据模型（核心）

```sql
-- 提示词主表
CREATE TABLE prompts (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    description TEXT,
    category TEXT,
    model_tags TEXT,
    is_pinned INTEGER DEFAULT 0,
    is_favorite INTEGER DEFAULT 0,
    rating INTEGER DEFAULT 0,
    created_at DATETIME,
    updated_at DATETIME
);

-- 版本历史表
CREATE TABLE prompt_versions (
    id INTEGER PRIMARY KEY,
    prompt_id INTEGER REFERENCES prompts(id),
    version TEXT NOT NULL,
    content TEXT NOT NULL,
    change_summary TEXT,
    created_at DATETIME
);

-- 标签表
CREATE TABLE tags (
    id INTEGER PRIMARY KEY,
    name TEXT UNIQUE NOT NULL,
    parent_id INTEGER REFERENCES tags(id)
);

-- 提示词-标签关联
CREATE TABLE prompt_tags (
    prompt_id INTEGER REFERENCES prompts(id),
    tag_id INTEGER REFERENCES tags(id),
    PRIMARY KEY (prompt_id, tag_id)
);

-- 项目表
CREATE TABLE projects (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    color TEXT,
    icon TEXT,
    status TEXT DEFAULT 'active',
    default_model TEXT,
    variables_schema TEXT,
    created_at DATETIME,
    updated_at DATETIME
);

-- 提示词-项目关联
CREATE TABLE prompt_projects (
    prompt_id INTEGER REFERENCES prompts(id),
    project_id INTEGER REFERENCES projects(id),
    PRIMARY KEY (prompt_id, project_id)
);

```

## 9. 验收标准

- 可创建、编辑、删除提示词，并本地持久化。
- 可通过关键词、分类、标签、项目联合检索。
- 可将提示词模板化，填写变量后一键复制。
- 修改提示词自动生成版本，可 Diff 对比并回滚。
- 可通过 WebDAV + 加密口令完成多设备同步与恢复。
- 本地数据库加密，API Key 存储于 OS 钥匙串。
- 可导出加密备份，并支持导入恢复。
- 可选启用应用锁和自动锁定。
- 团队场景下可共享工作区，支持只读/可编辑权限。
- 可导出 .promptpack / .projectpack 并导入。

## 10. 风险与假设

| 风险/假设 | 说明 | 应对 |
|---|---|---|
| 同步冲突复杂 | CRDT 实现难度较高 | 先支持字段级 LWW，后续引入 HLC |
| 密钥丢失 | 用户忘记同步口令 | 提供 12 词恢复短语，强调离线保存 |
| 团队功能过度设计 | 个人用户可能不需要 | 团队能力全部 P3，按需启用 |
| 浏览器插件平台限制 | ChatGPT/Claude 页面结构变化 | 插件保持轻量，优先剪贴板方案 |
| WebDAV 兼容性 | 不同服务商实现差异 | 优先适配坚果云、群晖、Nextcloud |
| 本地模型性能 | 小设备运行慢 | 在线 API 作为可选补充 |
